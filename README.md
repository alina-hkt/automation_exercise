- 🌐 **Browser & API Automation:** Playwright
- 📊 **Reporting:** Allure Report
- ✨ **Linting & Formatting:** Ruff
- 🐳 **Containerization:** Docker
- 🔄 **CI/CD:** GitHub Actions
